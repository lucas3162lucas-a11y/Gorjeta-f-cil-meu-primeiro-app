Como funciona sem root

O Melty Droid não altera nenhum app. Ele cria o mod no formato oficial do jogo (add-on do Minecraft, mod do Luanti) e entrega para o próprio jogo importar. Por isso só funcionam jogos que aceitam mods oficialmente.

Melty Droid é um projeto independente, sem ligação com o Melty oficial nem com os jogos suportados.
